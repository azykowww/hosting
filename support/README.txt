Match3Poker — сайт поддержки и политики конфиденциальности

Структура:
  index.html                 — страница поддержки (Support URL)
  privacy/index.html         — политика конфиденциальности (Privacy Policy URL)
  privacy/Match3Poker_Privacy_Policy.pdf — PDF-версия политики (EN)
  .nojekyll                  — служебный файл для GitHub Pages, не удалять

Как опубликовать на GitHub Pages (бесплатно):
  1. Создайте на github.com публичный репозиторий, например match3poker.
  2. Загрузите в него содержимое этой папки (Add file → Upload files),
     включая папку privacy и файл .nojekyll.
  3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
  4. Через 1–2 минуты сайт будет доступен по адресу:
       https://<ваш-логин>.github.io/match3poker/
  5. Ссылки для магазинов:
       Support URL:        https://<ваш-логин>.github.io/match3poker/
       Privacy Policy URL: https://<ваш-логин>.github.io/match3poker/privacy/

Альтернатива: перетащите эту папку на app.netlify.com/drop — получите ссылку сразу.
