# Hello, World!

Простой статический сайт для бесплатного хостинга на GitHub Pages + Cloudflare.

## Как выложить

1. Создайте на github.com публичный репозиторий `ваш-ник.github.io`.
2. Нажмите **Add file → Upload files** и перетащите все файлы из этой папки (не саму папку).
3. Откройте **Settings → Pages**, выберите **Deploy from a branch → main / (root)**.
4. Через пару минут сайт откроется на `https://ваш-ник.github.io`.

## Свой домен через Cloudflare

1. Добавьте домен в Cloudflare (бесплатный план) и пропишите у регистратора выданные NS-серверы.
2. В DNS добавьте A-записи для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, и CNAME `www` → `ваш-ник.github.io`. Пока что — серое облачко (DNS only).
3. В GitHub: **Settings → Pages → Custom domain** — впишите домен, дождитесь сертификата, включите **Enforce HTTPS**.
4. В Cloudflare переключите облачка на оранжевые, в **SSL/TLS** выберите режим **Full**.

## Что внутри

- `index.html` — главная страница
- `style.css` — стили (светлая и тёмная тема подстраиваются под систему)
- `404.html` — страница «не найдено», GitHub Pages подхватит её сам
- `favicon.svg` — иконка вкладки
